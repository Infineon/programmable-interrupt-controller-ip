# Documentation

This directory contains documentation for the interrupt controller, including
architecture, integration, and usage information.

## Contents

- [`interrupt_controller.adoc`](interrupt_controller.adoc) - Documentation of the interrupt controller's architecture, interrupt-processing behavior, integration, and usage.
- [`interrupts_by_group.txt`](interrupts_by_group.txt) - Interrupt-to-group
  assignments used by the priority-resolution logic.

Start with `interrupt_controller.adoc` when reviewing the controller
architecture and interrupt processing path. The grouping text file is a
compact reference for the interrupt-to-group assignments.
